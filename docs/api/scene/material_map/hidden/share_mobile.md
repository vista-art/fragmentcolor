# MaterialMap::share (mobile)

Mobile binding for `MaterialMap::texture` with another map, whose texture this map samples.
Uniffi has no method overloading, so the map form gets its own entry point
next to the `Texture` and texture input ones.
The Swift and Kotlin extensions expose it as the `texture(map)` overload.
