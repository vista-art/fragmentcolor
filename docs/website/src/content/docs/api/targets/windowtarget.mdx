## Description

[WindowTarget](/api/targets/windowtarget) is an implementation of [Target](/api/targets/target) that represents a rendering destination attached to a platform-specific window.

The [Target](/api/targets/target) object is a rendering destination for the [Renderer](/api/core/renderer).

It contains a GPU surface texture attached to a platform-specific window or an offscreen texture for headless rendering (see [TextureTarget](/api/targets/texturetarget)).

In Rust, we officially support Winit. Check the examples folder for details.

<TabItem label="Rust">

async fn run() -> Result<(), Box<dyn std::error::Error>> {
let canvas = fragmentcolor::headless_window([800, 600]);

### WindowTarget::size() -&gt; Size &#123; width, height, depth &#125; \{#size\}

Returns the size of the [WindowTarget](/api/targets/windowtarget) in pixels.
`depth` is absent for a window target in every language: `None` in Rust and
Python, `undefined` in JS, `nil` in Swift and `null` in Kotlin.

let size = target.size();

assert_eq!([size.width, size.height], [800, 600]);

### WindowTarget::resize(size: [u32; 2] | (u32, u32)) \{#resize\}

Resizes the [WindowTarget](/api/targets/windowtarget) to the given width and height.
Call it when the window or canvas changes size.

A minimized window reports 0×0. The target accepts it and keeps its last size, then draws at the new
size once the window has an area again. A side past the device limit returns an error.

#### Example

<Tabs>

<TabItem label="Rust">
<Code
code={`
async fn run() -> Result<(), Box<dyn std::error::Error>> {

use fragmentcolor::{Renderer, Target};

let renderer = Renderer::new();
let mut target = renderer.create_target(canvas).await?;

target.resize([1024, 768])?;

let size = target.size();
assert_eq!([size.width, size.height], [1024, 768]);
Ok(())
}
fn main() -> Result<(), Box<dyn std::error::Error>> { pollster::block_on(run()) }

### WindowTarget::get_image() \{#get_image\}

Returns an error for a [WindowTarget](/api/targets/windowtarget): a frame on screen can't be read back. JavaScript throws an `Error`, Python and Swift throw a `FragmentColorError`, and Kotlin throws a `FragmentColorException`.

To read the pixels of a frame, draw it into a [TextureTarget](/api/targets/texturetarget) and call `get_image` there, as the example does.

#### Example

<Tabs>

<TabItem label="Rust">
<Code
code={`
async fn run() -> Result<(), Box<dyn std::error::Error>> {
let canvas = fragmentcolor::headless_window([800, 600]);
use fragmentcolor::{Renderer, Shader, Target};

let renderer = Renderer::new();
let target = renderer.create_target(canvas).await?;
let shader = Shader::default();
renderer.render(&shader, &target)?;

// The same frame, drawn where it can be read back.
let offscreen = renderer.create_texture_target([800, 600]).await?;
renderer.render(&shader, &offscreen)?;
let image = offscreen.get_image().await?;
assert_eq!(image.len(), 800 * 600 * 4);
Ok(())
}
fn main() -> Result<(), Box<dyn std::error::Error>> { pollster::block_on(run()) }
`}
lang="rust" meta="collapse={1-2, 14-17}"
/>

</TabItem>
