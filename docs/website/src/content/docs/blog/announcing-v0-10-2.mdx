v0.10.2 adds a first Python implementation of FragmentColor and publishes it to PyPI. It follows the cleanup in [v0.10.1](/blog/announcing-v0-10-1/), and the next releases build on it: [v0.10.4](/blog/announcing-v0-10-4/) fixes the package import, and [v0.10.5](/blog/announcing-v0-10-5/) brings Python to Windows and Linux.

Release notes: [CHANGELOG](https://github.com/vista-art/fragmentcolor/blob/main/CHANGELOG.md#0102-python-support).
