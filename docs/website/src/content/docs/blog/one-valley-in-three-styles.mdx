The [valley in the playground](/welcome/playground/#walk) has a new key. Press M while you walk, and every pine, boulder, tuft of grass and lamp changes how it takes the light: physically based first, then cel shaded, then flat color with no lighting at all. Phones get a Style button above the fullscreen one. A label in the corner names the look you're in.

Each look is one of the material types that 0.12.8 brings: [`PbrMaterial`](/api/scene/pbrmaterial/), [`ToonMaterial`](/api/scene/toonmaterial/) and [`UnlitMaterial`](/api/scene/unlitmaterial/).

## A type for each shading model

Until 0.12.8, `Material::pbr()` built the one material the renderer shipped, and `Material::custom(shader)` wrapped anything else. Now each shading model is a type with the settings it reads and nothing more.

`PbrMaterial` is glTF's metallic-roughness model, what `Material::pbr()` used to build. `UnlitMaterial` draws its base color times its map and the vertex color, which suits UI, sprites, baked lighting and debug views. `ToonMaterial` cuts each light into flat steps, three by default, or reads the steps from a gradient texture. On top of that it can add a hard highlight where the light glints and a rim color along the edges the camera sees.

A [`Shader`](/api/core/shader/) of your own is the fourth kind. `Model::new` takes it as it is, and the renderer fills its `camera`, `lights` and `model` slots as it fills them for the built-in types.

## Three models on every spot

The valley builds each surface three times. A small helper takes the PBR material a surface already had and adds a toon and an unlit one in the same color:

```js
function styles(pbr, color = [1, 1, 1, 1], mode = AlphaMode.Opaque) {
  return {
    pbr: pbr.baseColor(color).alphaMode(mode),
    toon: new ToonMaterial().baseColor(color).bands(3).rim(RIM).alphaMode(mode),
    unlit: new UnlitMaterial().baseColor(color).alphaMode(mode),
  };
}
```

Every tree, rock and lamp then becomes three `Model`s over one `Mesh`, one per material. Pressing M hides the current style's Models with `setVisible(false)` and shows the next style's. A hidden Model stays in its pass but costs no draw call, and the switch only flips each Model's flag.

The world's assets are faceted already, each triangle shaded flat, and by day toon shading changes them less than you might expect. Its steps show on the snow. After dusk the rims take over, and every pine stands out against the dark.

Flat ground needs care with a rim. Seen far away it meets the eye edge-on, and a rim would light every distant stretch of meadow as a pale band. The ground and the pond take no rim. The pond gets a hard toon highlight instead, and a lamp's bulb glows through a rim as wide as the bulb itself, updated each frame from the color behind the PBR bulb's emissive light.

Unlit drops the sun and the lamps entirely and keeps the vertex colors. The valley reads like a flat painting of itself.

## A label drawn in WGSL

The corner label is a third pass, drawn over the scene with blending. A 5x5 bitmap font in `label.wgsl` spells PBR, TOON or UNLIT from a number the program sets with `label.set("label.style", style)`. A label on the page would exist only on the web. Drawn in the shader, it shows the same in the Rust, Python, Swift and Kotlin tabs.

## Maps that chain

Each texture a material samples is now a [`MaterialMap`](/api/scene/materialmap/), and its calls chain: the texture, the UV set it reads and the transform on those UVs. In Rust:

```rust
gold.normal_map().texture(&tiles)?.uv(1)?.transform([0.0, 0.0], [4.0, 4.0], 0.0)?;
```

A refused call names the map and changes nothing, as in `PbrMaterial::normal_map().transform: rotation must be finite, got NaN`.

## Also in 0.12.8

- A storage `set` uploads only the bytes it changes. What a compute pass wrote in the rest of the root stays, and two Renderers that draw one shader each keep their own output.
- Swift and Kotlin throw the error class Python raises, with the same message and fields, and one [Errors](/api/errors/) page lists them all.
- A mirrored `Model` with a double-sided material lights its outer faces as the front, and a mirrored normal map lights its bumps from the side they face.
- Playground demos that take keys can list touch buttons, as the valley does for its Style button.

0.12.8 changes signatures in every language. Pin 0.12.7 until your code follows the upgrade notes in the [changelog](https://github.com/vista-art/fragmentcolor/blob/main/CHANGELOG.md).
